# mdjudge

Judgement requests over the mddb card substrate: agents post one question
with bounded evidence; the human answers from a surface no agent runs on.
Design: ~/notes/mdjudge-schema.md.

## Producer discipline (from the first live round)

A card whose answer destroys something must lead with what is destroyed and
what is unique about it; reassurance about things not at risk is persuasion,
not briefing. Evidence states facts as of when it was gathered — the surface
shows the card's age, and a producer acting on an old answer re-verifies the
world before the act, because approved_sha pins the card, never the world.
Prefer the short default expiry: a question worth a week of waiting is worth
re-asking with fresh evidence.
